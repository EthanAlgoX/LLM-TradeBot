# TradeBot Web Console

- Scope: full replacement of the existing single-page Web console.
- Mode: Operate.
- Audience and job: a human operator supervising sequential Paper cycles, current exposure, evidence, and strategy releases.
- Primary task: understand system mode, position and risk, release stage, last decision cause, and required human action within three seconds.
- Constraints: Agent-first, Copilot constrained to read-only queries and draft creation, no direct strategy mutation, no exchange write path, emergency pause affects new openings only.
- Direction: flight recorder plus strategy release control room. Graphite instrument surfaces, compact system typography, low-radius hard edges, one muted chartreuse operational accent, semantic risk colors, causal traces, and no decorative glow.
- Memorable moment: the live Agent topology behaves as an inspectable evidence circuit. Selecting any node replaces the adjacent input/output artifact detail without leaving the cycle.
- Responsive rule: wide screens show navigation, cockpit, and Copilot concurrently; narrow laptops move Copilot below the primary cockpit; small viewports linearize all topology and preserve every control.
- Mock boundary: all Web data remains synthetic but mirrors Paper Account, Paper Cycle Journal, Stage Event, Agent Artifact, Trade Review, Strategy Profile, Backtest, and Walk-Forward field names.
