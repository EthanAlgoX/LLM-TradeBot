# 策略编辑器交互

Agent 的定义和编排已经从策略编辑器拆到“Agent 中心”。Agent 库中的每次编辑都会新增不可变模板版本；归档模板不会改写已发布工作流中的历史快照。多 Agent 工作流拥有独立草稿和正式版本，可保存节点、上下游、连接类型、condition 与字段映射，经过静态检查后发布。旧 StrategyVersion 的内嵌图可显式导入为新工作流草稿，不会在读取页面时自动迁移或改写历史。

策略编辑器保留研究对象、数据来源、Agent 工作流选择和决策边界。草稿只能选择已发布工作流版本；选择时服务端以工作流正式版本为权威来源，将 `agentWorkflowVersionId` 和完整 Agent/Connection 快照同时冻结到 StrategyVersion。现有研究运行继续读取 StrategyVersion 子表，不会跟随 Agent 模板或工作流后续修改。迁移前策略仍可读取原有内嵌图，但页面会明确提示先去 Agent 中心导入并发布。

“策略配置”面板直接编辑当前 Draft 已持久化的 `riskPolicy`、`decisionPolicy`、`memoryPolicy` 和 `dataPermissionSnapshot`。`dataPermissionSnapshot` 不再显示为原始 JSON，也不再对应“输入 Agent”；新草稿默认启用系统 K 线、新闻和基本面连接，其中 K 线为必备来源，用户不需要为每个策略重复配置。研究市场是数据路由的上游约束：选择 A 股、港股或美股后，K 线、新闻、基本面和其他来源只列出标注支持该市场的候选；切换市场会把不兼容的固定提供方退回兼容自动来源、移除不兼容扩展来源，并清空原市场固定股票代码。服务端校验仍是最终边界，不能通过旧页面状态保存或发布跨市场组合。

数据中心目录为每个新登记来源保存 `kind` 与 `markets`；适用市场可多选，但不可为空。自定义 K 线、新闻、基本面和其他研究来源都进入同一目录，而不是只登记“其他数据”。目录只保存无密钥的连接标识，第三方凭据仍由设置模块管理；“已登记”只表示可被策略引用，不代表远端连接已经健康。历史上没有市场标签的旧目录项继续可读，并明确显示为未限制市场，避免迁移时破坏既有正式版本。数据配置定义版本可消费的输入范围，实际数据覆盖仍由运行和回放检查报告。其中“决策有效期”写入 `riskPolicy.decision_validity.max`，是图校验要求的发布前置条件；配置和 Agent 图共用同一个 Draft 保存接口。Published 版本中这些输入均为原生 disabled/read-only，服务端仍会拒绝任何修改请求。

六个官方策略模板都必须预置发布前必填的风险策略字段（包括 `riskPolicy.decision_validity.max`）。从模板复制得到的新草稿应立即通过“检查策略”。检查 Agent 链路通过后，编辑器同时开放“运行回测（可选）”和“正式发布”：历史回测不阻断发布，但未回测的已发布版本不得被描述为已经验证有效。

从模板复制策略时，策略中心使用独立命名弹窗并给出不与现有策略冲突的“副本”名称。前端会即时阻止已加载列表中的重名，服务端仍作为最终唯一性校验；API 拒绝创建时弹窗保留输入并展示真实原因，便于用户原地修改后重试。

冲突响应保留 `VERSION_CONFLICT`、服务器 revision 与更新时间的结构化错误载荷；前端据此暂停自动保存并保留本地内容，不会静默覆盖服务器草稿。

映射编辑器以 dot path 表示嵌套字段，展示类型、描述与 required，并在 UI 中提示重复目标映射和基础类型不兼容。服务端图校验是最终权威。

保存状态为 CLEAN、DIRTY、SAVING、SAVED、SAVE_FAILED、CONFLICT 和 READ_ONLY。冲突暂停自动保存，可查看非持久化预览差异、加载服务器版本，或将本地内容事务化分叉为新策略。Published、Deprecated 和 Archived 版本均完整只读，但可查看边、版本差异并基于版本创建 Draft。

运行中心将“运行一次”和“持续运行”分开展示。二者都只选择已发布策略版本，不提供独立的单标的运行或股票代码输入。持续运行可选择间隔，并配套暂停、终止和当前/下次状态说明。数据连接和股票池在策略配置中冻结，运行中心只执行已发布策略。官方起步模板展示 ANALYSIS → DECISION → REFLECTION：系统先按版本配置准备输入，再分析、形成研究决策提案并复盘。没有可用 LLM 时，开始按钮显示配置提示而不会创建注定无法完成分析的批次。这里的“运行”是自动选股与研究，不代表已经下单或获得收益。

活动批次会自动刷新候选和每个子 Agent 的文本状态：等待执行、正在执行、已完成、执行失败或已取消。点击候选可进入独立详情页；详情每两秒刷新，显示全部 Agent 阶段、已返回输出及失败原因。状态不只通过颜色表达。

策略中心列表只负责进入具体策略，不直接展示“删除”按钮。“删除策略”位于策略详情编辑器中：只有草稿、从未发布的策略可直接删除；已发布策略必须确认它将从可运行列表移除，正在运行的策略还会明确提示将终止持续运行并取消未完成研究。服务端会重新校验这些影响，不依赖浏览器的过期状态。删除为可审计的软删除：策略从活动列表移除，但不变更或物理删除已发布版本、验证实验和审计记录。
